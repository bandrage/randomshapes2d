# RandomShapes2D

一个在浏览器里运行的随机几何绘图工具。用笔刷在画布上拖动，可以连续生成随机的几何形状；也可以自由画线、用套索填充或擦除。

纯前端单文件实现，无任何依赖，打开即用。

## 在线访问

https://bandrage.github.io/randomshapes2d/

## 功能

### 放置

在画布上拖动，按固定间距连续生成随机几何形状。

- **形状**：随机、多边形、星形、矩形、圆、扇形、线、十字、放射、墨块、自定义
- **笔触**：大小、大小变化、间距、抖动、透明度、线宽
- **控制模式**：
  - 散布 — 沿拖动轨迹按间距连续生成
  - 拖拽 — 拖动距离决定大小，拖动方向决定旋转，抬起确定
- **绘制模式**：
  - 线 — 只有空心轮廓
  - 填充 — 实心剪影
  - 混合 — 每次随机描边或填充

### 自定义形状

选中「自定义」后右上角出现面板，包含 5 个槽位。

- 点击槽位进入框选模式，在画布上拖框，框内内容会被截取为该槽的形状
- 每个槽位下方有权重滑杆（0–10），决定放置时的出现概率
- 五个滑杆总和不能超过 10
- 只有已载入且权重大于 0 的槽位参与随机抽取

### 绘画

- **线** — 自由画线，用中点加贝塞尔曲线平滑。线的颜色由「色相」和「渐变」共同决定，沿长度方向平滑推进，或按随机颜色跳变
- **填充** — 柳叶笔式套索，以起点为圆心，360° 分成 72 个扇区，每个扇区一个颜色。色相跨度由「渐变」控制，0% 纯色，100% 覆盖完整色环
- **擦除** — 同样的套索，但圈住的区域会从画布上移除

### 颜色

色相、渐变、随机颜色、饱和度、亮度、混合模式、背景色。

色相条上方有预览，白线是基础色相，半透明区域是当前渐变覆盖的范围。

### 粘贴图片

按 `Ctrl+V`（Mac 为 `Cmd+V`）可以把剪贴板里的图片粘贴到画布上，自动缩放到视口 80% 以内，保持长宽比。

### 画布操作

- **撤销** — 回退上一步（`Ctrl/Cmd + Z`）
- **清空** — 清除所有内容
- **保存** — 导出为带透明通道的 PNG，不含背景色

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + V` | 粘贴剪贴板里的图片 |
| `Esc` | 退出框选模式 |
